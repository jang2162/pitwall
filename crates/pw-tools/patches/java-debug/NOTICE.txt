  Change:  the constructor opens its server socket with
             new ServerSocket(0, 1, java.net.InetAddress.getLoopbackAddress())
           instead of
             new ServerSocket(0, 1)
  Why:     the upstream server listens on every network address, accepts
           connections with no authentication for as long as the language
           server runs, and serves the debug protocol's `launch` request, so
           another machine on the same network could run programs as the
           user. Bound to the loopback address, only this machine can connect.
