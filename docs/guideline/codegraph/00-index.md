# 인덱스가 없을 때

## codegraph 가 「not initialized」 로 답하면 인덱스를 직접 만들지 않는다 — 사용자에게 세팅 문서를 알린다

`.codegraph/` 가 없으면 서버는 떠 있어도 조회가 되지 않는다. 그때는 grep·Read 로 작업을 이어 가고, 사용자에게 `docs/guideline/codegraph/SETUP.md` 로 인덱스를 만들지 한 줄로 묻는다.

- **Why:** 인덱스를 만들지는 프로젝트 사람이 정한다(저장소 크기, 커밋 여부). 에이전트가 알아서 만들면 `.codegraph/` 가 예고 없이 작업 트리에 생긴다. 안 만들고 넘어가면 MCP 가 있는데도 매번 grep 으로 돌아간다.
- **How to apply:** 사용자가 승낙하면 그때 세팅 문서의 순서로 만든다. 거절하면 이 세션에서 다시 묻지 않는다.
