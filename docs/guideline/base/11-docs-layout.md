# 문서를 어디에 두는가

## `docs/` 바로 아래에는 문서를 만들지 않고, 수명으로 갈래를 골라 그 안에 만든다

고르는 질문은 하나다 — **「이 문서는 언젠가 지우는가?」**

| 종류 | 경로 | 수명 | git |
| --- | --- | --- | --- |
| 규칙·가이드(정본) | `docs/guides/` | 계속 산다 | 커밋 |
| 사용자 매뉴얼 | `docs/manual/` | 계속 산다 | 커밋 |
| 결정 기록 | `docs/adr/` | 계속 산다 | 커밋 |
| API 명세 | `docs/api/` | 계속 산다 | 커밋 |
| 운영(반영 절차·체크리스트·롤아웃 레시피·과도기 참고 자료) | `docs/ops/` | 일이 끝나면 지운다 | 커밋 |
| 설계·계획 | `docs/superpowers/specs/`, `docs/superpowers/plans/` | 이력으로 남는다 | 커밋 |
| 이력으로 남길 판단 기록 | `docs/superpowers/reports/` | 이력으로 남는다 | 커밋 |
| 워커·에이전트 사이 전달 문서 | `.superpowers/handoff/` | 읽으면 끝이다 | **gitignore** |
| 세션 스크래치·임시 산출물 | `.superpowers/`, `temp/` | 읽으면 끝이다 | **gitignore** |

필요한 갈래만 만든다. 위에 없는 종류는 가장 가까운 수명의 갈래에 둔다. `docs/guideline/` 은 공용 지침 사본 자리이므로 직접 쓰는 문서를 두지 않는다.

- **Why:** 수명이 다른 문서가 한 자리에 있으면 읽는 사람이 어느 것이 아직 유효한지 스스로 가려야 한다. 대개 가리지 않고 둘 다 규칙으로 읽는다. 지워질 문서를 코드 주석이나 다른 문서가 가리키면 지운 뒤 그 인용이 조용히 죽는다.
- **How to apply:**
  - **갈래가 애매하면 `ops/` 로 시작한다.** 규칙으로 굳으면 `guides/` 로 올린다. 반대 방향(정본이었다가 지워지는 것)이 훨씬 비싸다.
  - **`ops/` 문서를 규칙의 정본으로 삼지 않는다.** 코드와 다른 문서가 가리킬 것은 `guides/` 의 절 제목이다(`base` 스택 「인용과 문서」).
  - **일이 끝난 `ops/` 문서는 문서째 지운다.** 그 안에 일이 끝난 뒤에도 참인 규칙이 있으면 먼저 `guides/` 의 해당 절로 올리고 나머지를 걷는다. 「기록으로」 남겨 두지 않는다 — 남기면 다음 사람이 지금 절차로 읽는다. 기록은 git 이 갖는다.
  - **`docs/superpowers/` 는 그 시점의 판단 기록이다.** 지금 참인 규칙의 근거로 인용하지 않는다.

## 파일 이름은 영문 소문자 kebab-case 로 쓴다

`docs/guides/dev-environment.md` 처럼 쓴다. 이력 문서는 앞에 날짜를 붙인다 — `2026-09-02-<주제>-report.md`.

- **Why:** macOS 기본 파일 시스템은 대소문자를 구분하지 않아 `API.md` 와 `api.md` 가 한 파일로 부딪친다. 한글·공백이 든 이름은 링크와 셸 명령에서 따옴표나 인코딩을 따로 챙겨야 하고, 빠뜨리면 경로가 조용히 갈라진다.
- **How to apply:** 기존 문서의 이름을 바꿀 때는 그 문서를 가리키던 링크와 인용을 함께 고친다.

## README 는 안정 문서만 링크하고, 에이전트가 읽을 정본은 지침의 색인이 가리킨다

README 는 사람이 처음 여는 자리다. 거기서는 `docs/guides/` 와 `docs/manual/` 의 문서만 링크한다. 에이전트가 특정 작업에서 읽어야 하는 `guides/` 의 문서는 지침 파일의 색인에 「언제 읽는가」 로 올린다.

- **Why:** README 가 `ops/`·`superpowers/`·`.superpowers/` 를 링크하면 그 문서를 지우는 순간 죽은 링크가 남는다. 에이전트는 파일 이름만 보고 지금 작업에 필요한지 판단하지 못하므로, 색인에 없는 정본은 읽히지 않는다.
- **How to apply:** 색인은 「~할 때」 로 끝나는 작업 시점과 저장소 루트 기준 경로로 쓴다. 새 `guides/` 문서를 만들었으면 README 와 지침 색인 중 어디에 올릴지 정한다.
