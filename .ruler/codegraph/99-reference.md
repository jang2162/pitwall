# codegraph 참조 지침

아래 작업을 할 때는 **시작하기 전에** 그 파일을 읽는다. 이 규칙들은 상시 지침에 없다.

| 언제 | 읽을 파일 |
| --- | --- |
| codegraph MCP 로 구조 질문(호출 관계, 영향 범위, 심볼 위치)을 하려 하거나, codegraph 가 「not initialized」 로 답할 때 | `docs/guideline/codegraph/00-index.md` |
| orca.yaml 의 scripts.setup 을 만들거나 고칠 때, codegraph 를 쓰는 저장소에서 Orca 워크트리를 세팅할 때 | `docs/guideline/codegraph/01-orca-setup.md` |
